# Daten

| Ordner | Inhalt | Im Repo? |
|--------|--------|----------|
| `rohdaten/` | Audioaufnahmen, Original-Transkripte, Umfrage-Exporte mit Zeitstempeln/IPs, Einwilligungen | **nein** (per `.gitignore` ausgeschlossen) |
| `aufbereitet/` | anonymisierte Transkripte, bereinigte Datensätze ohne Personenbezug | ja |

## Regeln

- Personenbezogene Rohdaten speichern Sie nur lokal oder in einem zugriffsbeschränkten Ordner der Universität (z. B. academiccloud), **nie** in diesem Repo, auch nicht in einem privaten Repo
- Vor dem Commit prüfen: Enthält die Datei Namen, E-Mail-Adressen, Matrikelnummern, Arbeitgeber oder andere Merkmale, über die Personen identifizierbar sind? Dann erst anonymisieren
