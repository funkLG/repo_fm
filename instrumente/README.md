# Instrumente

Hier liegen alle Erhebungsinstrumente in ihrer jeweils aktuellen Version. Ältere Versionen müssen Sie nicht aufheben.

| Datei | Inhalt |
|-------|--------|
| `leitfaden.md` | Interviewleitfaden (qualitativ) |
| `fragebogen.md` / LimeSurvey-Export (`.lss`) | Fragebogen mit Konstrukten, Items und Quellen der Skalen (quantitativ) |
| `versuchsaufbau.md` | Treatments, Ablauf, Randomisierung, ggf. Präregistrierung (Experiment) |
| `einwilligung.md` | Information und Einwilligungserklärung für Teilnehmende |
| `codebook.md` / `.xlsx` | Codebook für die qualitative Auswertung |

Legen Sie nur die Dateien an, die Sie für Ihre Methode brauchen.

## Mindestinhalt der Einwilligung

- Wer forscht (Team, Veranstaltung, Leuphana Universität Lüneburg) und wozu?
- Was passiert in der Erhebung, wie lange dauert sie?
- Teilnahme ist freiwillig und kann jederzeit ohne Nachteile abgebrochen werden
- Welche Daten werden erhoben (z. B. Audioaufnahme), wie werden sie gespeichert, anonymisiert und wann gelöscht?
- Wer hat Zugriff?
- Kontakt für Rückfragen
