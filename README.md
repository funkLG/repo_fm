## Spielregeln

- **Datenschutz:** Keine personenbezogenen Daten (Audioaufnahmen, nicht anonymisierte Transkripte, Rohdaten mit Namen/E-Mail) ins Repo. Der Ordner `daten/rohdaten/` ist per `.gitignore` ausgeschlossen. Details in [`daten/README.md`](daten/README.md)
- **KI-Nutzung:** Dokumentieren Sie, wofür Sie KI-Werkzeuge einsetzen, in [`docs/ki-nutzung.md`](docs/ki-nutzung.md)
- **Arbeitsweise:** Kleine, häufige Commits mit aussagekräftiger Nachricht (`Leitfaden v2 nach Pilotinterview`) statt eines großen Uploads am Ende. Die Commit-Historie zeigt auch, wer was beigetragen hat
