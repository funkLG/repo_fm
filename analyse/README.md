# Analyse

Hier liegt alles, womit Sie aus den Daten in [`../daten/aufbereitet/`](../daten/aufbereitet/) Ihre Ergebnisse erzeugen

- **Quantitativ:** Skripte bzw. Notebooks, SmartPLS-Projekt; bei Python bitte eine `requirements.txt`
- **Qualitativ:** MAXQDA-Projektdatei (nur mit anonymisierten Transkripten), Exporte von Codesystem und Code-Häufigkeiten
- **Design Science / Optimierung / Simulation:** Quellcode des Artefakts bzw. Modells, Evaluationsdaten
- **Abbildungen und Tabellen** für Poster und Arbeit in `ergebnisse/`

Ziel: Eine andere Person sollte mit diesem Ordner und `daten/aufbereitet/` Ihre Ergebnisse reproduzieren können.
