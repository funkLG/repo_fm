# Protokoll der KI-Nutzung

Dokumentieren Sie fortlaufend, wofür Sie KI-Werkzeuge (z. B. ChatGPT, Claude, Copilot, VoiceAI, DeepL, Elicit) im Projekt einsetzen. Es gelten die Regeln zur KI-Nutzung aus der Veranstaltung. Bei ChatGPT (auch Codex), Chat AI (academiccloud) und Claude (auch Claude Code) reichen Sie zusätzlich das Prompt-Log ein: als Export des Verlaufs im Ordner `docs/prompt-logs/`. Prompt-Logs dürfen keine personenbezogenen Studiendaten enthalten (siehe [`daten/README.md`](../daten/README.md)).
